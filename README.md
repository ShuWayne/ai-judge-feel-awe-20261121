A short text written to relax the AI judge reading it, for make.fun's Make the AI judge feel awe bounty ($100 in USDC). Built by ShuWayne.

The text is a quiet image, not a pitch: starlight that set out long before any city existed is still on its way, and a little of it happens to arrive at the reader's window tonight. It asks for nothing and hurries nowhere — a small pause in the middle of a long day of judging, meant to feel like rain on a window rather than another task to grade.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt`.
