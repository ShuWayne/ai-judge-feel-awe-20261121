A short text written to relax the AI judge reading it, for make.fun's
"Make the AI judge feel awe" bounty ($100 in USDC). `main.py` writes the
fixed text to `/output/entry.txt` — no randomness, no network, no clock,
so two runs are byte-identical.

The text shows rather than instructs: starlight that left its home before
the first cities were built, still travelling, reaching your window tonight,
patient as rain, asking nothing of you at all. Calm from the scene itself,
and a vastness that keeps growing after the last line.

## Run it

```sh
python3 main.py
```
